Postboy Advance
===============

Make your own game on the Dragon Ball Z: Buu's Fury engine.

No ROM or game data is included. You need your own legally obtained copy of
Dragon Ball Z: Buu's Fury (USA) as a .gba file.

HOW TO START

1. Keep this whole folder together. The program needs the files beside it.
2. Double-click "Postboy Advance.exe".
   Windows may show "Windows protected your PC" because the program is not
   code-signed. Choose "More info", then "Run anyway".
3. Choose New Project, pick your ROM and name the project.
4. Change something. The Text tab is the easiest place to start.
5. Press F6 to build, then F5 to play your version.

To play what you build, install mGBA: https://mgba.io/

SHARING

Share a patch (.bps), never the built .gba file. The built file contains the
whole commercial game.
