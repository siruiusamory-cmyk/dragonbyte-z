# Research and evidence catalogue

This catalogue routes the retained evidence collection by topic. Start with
[reverse-engineering notes](../reverse-engineering.md) and the
[documentation index](../README.md) for active workflows. The files below are
measurements and records, not installation instructions.

## Reading an evidence record

- A claim applies to its named profile, baseline and measured operation.
- `CONFIRMED`, `INFERRED` and `UNKNOWN` retain their meanings from
  [development policy](../DEVELOPMENT.md).
- A round-trip, successful build and runtime observation prove different things.
- Detailed addresses, disassembly and test transcripts stay in these records.
- The [capability registry](../../src/data/capabilities.json) describes shipped
  editor surfaces; the [coverage summary](ROM_EDITOR_COVERAGE_SUMMARY.md)
  describes a separate, baseline-pinned census of engine systems.

Files stay at stable paths to preserve source, test and document citations.
Historical figures are not current completion claims. Missing private closure
artifacts are identified where cited; no replacement evidence is invented.
