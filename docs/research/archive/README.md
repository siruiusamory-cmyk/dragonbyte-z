# Research archive

Dated working records: content passes, review briefs, integration notes, audits and
checkpoints. They describe how a piece of work went at the time it was done. They
are kept for provenance and are not current guidance.

For what the tools do today, read the [research catalogue](../README.md) and the
[SDK overview](../../sdk-overview.md). To make a game, read the
[user guide](../../creator.md).

Nothing in the code or the tests reads a file in this folder.
